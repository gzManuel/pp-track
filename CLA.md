## How to sign

The Project records agreement to this CLA in one of the following ways. **You
only need to do one:**

### Option A — Sign-off on every commit (DCO-style, preferred)

Add a `Signed-off-by` line to each commit. This certifies that you agree to
this CLA for that contribution:

```
git commit -s -m "your message"
```

This appends:

```
Signed-off-by: Your Name <your.email@example.com>
```

Use the same name and email as your GitHub account. To sign off commits you
already made on a branch, run `git rebase --signoff main`.
